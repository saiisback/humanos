# HumanOS

## Platform

Web mission console for a hackathon judge and a person delegating life administration.

## Stack

React and Vite, delegated in task instructions. Same-origin cookie API.

## Product truth

Prove uniqueness with World ID, review a generated mission, approve scoped capabilities, create an expiring ENS task agent, inspect independent Jev assessment and deterministic policy, approve exact actions and inspect durable receipts. Client presentation never grants authority. Unavailable integrations remain unavailable.

## Open decisions

Visual choices are implementation assumptions under the delegated premium responsive dashboard brief. No wallet-authentication API exists in the frozen contract; do not invent one.
